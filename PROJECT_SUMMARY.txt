🚀 DEPLOYMENT INSTRUCTIONS

Step 1: Access Shopify Theme Editor
├─ Log in to Shopify Admin
├─ Navigate to Online Store → Themes
├─ Find Dawn theme
└─ Click Actions → Edit code

Step 2: Upload Section Files
├─ Click Sections folder
├─ Add new section for each file
├─ Copy/paste content
└─ Save each file

Step 3: Upload Snippet Files
├─ Click Snippets folder
├─ Add new snippet for each file
├─ Copy/paste content
└─ Save each file

Step 4: Upload Template Files
├─ Click Templates folder
├─ Add new product template
├─ Name it "custom"
├─ Copy/paste content
└─ Save

Step 5: Upload Asset Files
├─ Click Assets folder
├─ Upload or add new asset
├─ Upload all 3 files
└─ Save

Step 6: Configure Homepage
├─ Go to Online Store → Themes → Customize
├─ Add sections in order:
│  1. Hero Halo
│  2. Category Grid
│  3. Featured Products
│  4. Halo Protocol
│  5. Trust Badges
└─ Customize settings via theme editor

Step 7: Test & Launch
├─ Preview on mobile/tablet/desktop
├─ Check all links and interactions
├─ Verify animations work smoothly
├─ Test accessibility features
└─ Go live!
